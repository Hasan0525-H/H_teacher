# المعلم H

تطبيق أندرويد احترافي للمعلم السعودي، يعمل بأسلوب **Offline-first** وقابل للتوسع.

## المرحلة الحالية
**الأساس + المناهج + الاختبارات + ملف الإنجاز**

تم تجهيز:
- Kotlin + Jetpack Compose + Material 3.
- MVVM.
- RTL عربي.
- Room + DataStore.
- إدارة المواد والصفوف والمناهج.
- استيراد وحفظ PDF أوفلاين.
- قارئ PDF محلي.
- بنك أسئلة ومولد اختبارات.
- PDF للأسئلة وPDF للإجابة.
- ملف إنجاز مهني محلي.
- بيانات المعلم: الاسم، المسمى، التخصص، المدرسة.
- تصنيفات ملف الإنجاز:
  - الدورات والشهادات.
  - تحضير الدروس.
  - الخطط العلاجية.
  - أوراق العمل.
  - الأنشطة.
  - تحليل النتائج.
  - الشواهد المهنية.
  - التقارير.
- إضافة وتعديل وحذف عناصر ملف الإنجاز.
- إرفاق ملفات وحفظ نسخة داخل التطبيق.
- تصدير ملخص ملف الإنجاز إلى PDF.
- توقيع Debug ثابت وversionCode متزايد في CI.

## الهوية الثابتة
- App name: **المعلم H**
- Application ID: `com.hasan0525.hteacher`
- Min SDK: 26
- Target / Compile SDK: 36

## قاعدة البيانات
- v1: subjects, grades, curricula, questions.
- v2: portfolio_items, portfolio_attachments.
- يوجد Migration صريح `MIGRATION_1_2`.
- لا يوجد `fallbackToDestructiveMigration`.

## التحديث
نسخ Debug الجديدة تستخدم توقيع تطوير ثابت.
إذا ثُبتت نسخة أقدم قبل اعتماد هذا التوقيع، يلزم حذفها مرة واحدة فقط، وبعدها يمكن تثبيت نسخ Debug اللاحقة فوق بعضها.

## الذكاء الاصطناعي
الأساس الحالي يعمل بدون إنترنت.
طبقة Cloud AI ستضاف بصورة اختيارية فوق بنك الأسئلة الحالي ولا تستبدل البيانات المحلية.

## القادم
1. الطلاب والحضور والدرجات والتقارير.
2. فهرسة المنهج إلى وحدات ودروس.
3. Cloud AI متعدد المزودات خلف بوابة آمنة.
