# المعلم H

تطبيق أندرويد احترافي للمعلم السعودي، يعمل بأسلوب **Offline-first** وقابل للتوسع.

## المرحلة الحالية
**v0.1.0 — الأساس + المناهج + مولد الاختبارات المحلي**

تم تجهيز:
- Kotlin + Jetpack Compose + Material 3.
- MVVM.
- RTL عربي.
- Room + DataStore.
- إدارة المواد والصفوف.
- استيراد وحفظ المناهج PDF أوفلاين.
- قارئ PDF محلي باستخدام Android PdfRenderer.
- بنك أسئلة محلي.
- أنواع: اختيار من متعدد / صح وخطأ / أكمل / مقالي.
- مستويات: سهل / متوسط / صعب.
- اختيار عدد الأسئلة والدرجة الكلية.
- اختيار أنواع الأسئلة والصعوبة.
- توزيع متوازن للأسئلة على الأنواع المختارة.
- توزيع الدرجات تلقائيًا.
- إنشاء نموذج اختبار داخل التطبيق.
- تصدير PDF للأسئلة.
- تصدير PDF مستقل لنموذج الإجابة.
- إنشاء ملفات PDF بالعربية عبر Android PdfDocument + StaticLayout.
- توقيع Debug ثابت لنسخ الاختبار.
- versionCode متزايد تلقائيًا في GitHub Actions.
- GitHub Actions يبني Debug APK تلقائيًا.

## التحديث وحماية البيانات
- Application ID ثابت.
- نسخ Debug من هذا الإصدار وما بعده تستخدم نفس مفتاح التطوير، لذلك يمكن تثبيت النسخ اللاحقة فوقها.
- GitHub Actions يستخدم رقم التشغيل لرفع `versionCode` تلقائيًا.
- إذا كان الجهاز يحتوي نسخة Debug أقدم بُنيت قبل تثبيت مفتاح التطوير الثابت، يلزم حذفها مرة واحدة ثم تثبيت أول نسخة بالتوقيع الثابت.
- مفتاح التطوير الموجود في المستودع مخصص للاختبار فقط ولا يُستخدم للإنتاج.
- مفتاح Release النهائي يجب حفظه خارج المستودع كسر/Secret دائم.

قاعدة Room تبدأ بالإصدار `1`.
لا يوجد `fallbackToDestructiveMigration`.
أي تغيير في schema يجب أن يضيف Migration صريحًا.

## ملاحظة عن الذكاء الاصطناعي
مولد الاختبارات الحالي يعتمد على بنك الأسئلة المحلي ويعمل بدون إنترنت.
طبقة الذكاء الاصطناعي السحابي ستضاف فوق نفس المحرك لاحقًا لتوليد الأسئلة تلقائيًا دون تغيير طريقة حفظها أو تصديرها.

## القادم
1. ملف الإنجاز الإلكتروني مع Migration صريح.
2. فهرسة محتوى المناهج وتقسيمه إلى وحدات ودروس.
3. توليد أسئلة تلقائيًا عبر Cloud AI متعدد المزودات.
4. الطلاب والحضور والدرجات والتقارير.
